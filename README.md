### Régimen de Promoción de las Prácticas

Se deben aprobar ambos exámenes parciales; hay dos fechas de recuperatorio, una para cada parcial. Para poder ser incluído en las Actas de Trabajos Prácticos es necesario haberse inscripto mediante el [sistema de inscripciones de la facultad](http://www.inscripciones.fcen.uba.ar) y haber completado la encuesta de evaluación docente. Se recuerda también que es obligatoria la lectura de las [Normas de higiene y seguridad](http://www.dm.uba.ar/varios/normseg.html).
